個人介紹網站｜科技風格 Bootstrap 5
==================================

檔案：
- index.html：網頁內容與 Bootstrap 5 元件
- style.css：科技風格與響應式樣式
- script.js：滾動動畫、導覽互動、年份更新

上傳方式：
1. 將 ZIP 解壓縮。
2. 在 cPanel 檔案管理員建立 public_html/profile/ 資料夾。
3. 將 index.html、style.css、script.js 上傳到該資料夾。
4. 開啟 https://你的網域/profile/。

注意事項：
- Bootstrap 5.3.3 使用 jsDelivr CDN 載入，瀏覽時需要網路連線。
- 本網站不需要 PHP、MySQL 或建置流程。
- 圓頂科技主視覺使用 CSS 製作，不需圖片素材。
- 若需要離線或完全自架 Bootstrap，可另行下載 Bootstrap CSS/JS 放到本機資料夾，並調整 index.html 的引用路徑。
- 網站內容是個人介紹示範，請自行確認姓名、經歷及外部連結是否符合公開需求。
